# Sistema de Gestión de Heladería

## 📋 Descripción del Proyecto

Este proyecto es un **sistema de gestión integral para una heladería** desarrollado en **Python**. La aplicación proporciona soluciones completas para administrar los diferentes aspectos operacionales de un negocio de helados.

### ¿Qué incluye?

- **Gestión de Base de Datos**: Modelo relacional optimizado para heladería
- **Interfaz Web**: Aplicación web desarrollada con Python
- **Módulos de Negocio**: Soluciones específicas implementadas en Python para:
  - Gestión de productos (sabores, tamaños, precios)
  - Control de inventario
  - Administración de pedidos
  - Gestión de clientes
  - Reportes de ventas

## 🛠️ Tecnologías Utilizadas

- **Python**: Lenguaje principal de desarrollo
- **Base de Datos**: Sistema relacional para almacenamiento de datos
- **Web Framework**: Aplicación web interactiva
- **Templates**: Interfaz de usuario responsiva
